⚙️ One-time setup: auto-read a shared link (iPhone Shortcut)

This Shortcut fetches the product page's code on your phone, pulls out the name, prices, clearance marker, and stock status, and hands them to Penny Run automatically. Build it once in the Shortcuts app:

  1. Open Shortcuts → tap + → rename it Send to Penny Run.
  2. In the shortcut's settings (ⓘ), turn on Show in Share Sheet and allow URLs and Text input.
  3. Add action Get URLs from Input (bind it to Shortcut Input).
  4. Add action URL Encode (acting on the URLs) — this keeps the link intact in the hand-off.
  5. Add action Get Contents of URL (acting on the URLs).
  6. Add action Get Text from Input (from the Contents).
  7. Add action Match Text (on that Text) and paste this pattern (it also harvests product links, so sharing a category page fills the Sweep list):
    (/p/[A-Za-z0-9][\w%-]{6,90}/\d{6,})|(<title>[^<]{5,160})|("price"\s*:\s*"?\d+(\.\d+)?)|("clearance"\s*:\s*\{)|(OUT_OF_STOCK|LIMITED_STOCK|BACKORDERED)|(\$\s*\d+\.\d{2})|([Cc]learance\s+[Ii]tem)|([Ww]as\s+\$\d+\.\d{2})|(\(\d{1,3}%\))
  8. Add action Combine Text (combine Matches, separator: New Lines).
  9. Add action URL Encode (on the Combined Text).
  10. Add action Text and build this — insert variable chips where the [brackets] are; after text= use the encode of the Combined Text (step 9), after url= the encode of the URLs (step 4):
    https://planetbandit.github.io/pennyrun/?text=[URL Encoded Text]&url=[URL Encoded Text from step 4]
  11. Add action Open URLs (on that Text). Done — in the HD app tap Share → Send to Penny Run.

Why not a full-page capture? Home Depot's page draws itself with JavaScript after loading, so PDF/screenshot renders only catch the empty shell — the page's raw code is where the data actually lives.

What it can and can't see: the fetch is anonymous, so it brings back the product name, internet #, online price, and general stock status — but not your store's in-store clearance price. Home Depot ignores a hand-set store cookie (tested: it returns a random store), so that number still comes from 📸 From a screenshot of the HD app.

Once this shortcut exists, Sweep (Checked tab) can call it directly: tap a category and it fetches that clearance page and fills the candidate list without you leaving Penny Run.
